# Content Schedule Manager

Minimal Content Schedule Manager — backend API (Express + SQLite) and a React (Vite) client.

Quick start (requires Node.js >=16):

1. Install server dependencies

```bash
cd server
npm install
npm run init-db
npm start
```

2. In another terminal, start client

```bash
cd client
npm install
npm run dev
```

API server runs on `http://localhost:4000` by default.

This is a minimal scaffold implementing Schedule Post CRUD, settings management, invitations, and a small React UI with Dashboard, List, and Settings pages.
